============================================
  배경 지우개 (게임 이미지 배경 투명화)
============================================

[실행]
  BG-Eraser.exe 를 더블클릭 (설치 필요 없음, 처음 실행은 몇 초 걸립니다)
  * Windows가 "PC를 보호했습니다"라고 하면  추가 정보 -> 실행  을 누르세요.
    (서명되지 않은 개인 제작 프로그램이라 나오는 안내입니다)

[사용 순서]
  1) 이미지 담기: 버튼으로 선택하거나 창에 끌어다 놓기 (폴더도 가능)
  2) 미리보기를 보며 조절 (체크무늬 = 투명)
       - 배경이 남으면 "배경 지우기 강도"를 올리세요.
       - 그림이 깎이면 강도를 내리세요.
       - 도트 그래픽은 "경계 부드러움"을 0으로 하세요.
  3) 투명화 시작!

[결과 저장]
  기본: 원본 이미지 옆에 "transparent" 폴더가 생기고 PNG로 저장
  "저장 위치 바꾸기" 또는 설정에서 원하는 폴더 지정 가능
  원본 파일은 바뀌지 않습니다.

[설정 (화면 오른쪽 위 '설정' 버튼)]
  - 언어: 한국어 / English / 日本語 / 中文 (바로 적용, 다음 실행에도 유지)
  - 캐시 정리: 오류 기록·임시 파일 삭제 (이미지는 지워지지 않음)
  - 자동 저장 경로: 확인·변경·기본값 복원·폴더 열기
  - 설정은 exe 옆의 settings.json 에 저장됩니다.

[창 크기]
  창을 키우거나 줄이면 화면 전체가 비율에 맞게 커지고 작아집니다.

[문제가 생기면]
  exe 옆에 error_log.txt 가 생겼다면 그 내용을 알려주세요.
