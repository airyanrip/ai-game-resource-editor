============================================
  배경 지우개 (게임 이미지 배경 투명화)
============================================

[실행 방법]
  1) 이 폴더의 "배경투명화.bat" 을 더블클릭
     (바탕화면의 "배경투명화" 바로가기도 같은 기능)
  2) 이미지 담기 -> 미리보기로 조절 -> 투명화 시작!

[폴더 구성]
  F:\배경투명화\
   ├─ 배경투명화.bat      ← 이것만 실행하면 됩니다
   ├─ 사용법.txt          ← 지금 보는 파일
   ├─ 폰트\               ← 도트 폰트 갈무리(Galmuri, 무료 OFL)
   └─ 프로그램\           ← 건드리지 마세요 (내부 파일)
       ├─ remove_bg_gui.pyw   화면(GUI) 프로그램
       ├─ remove_bg.py        배경 지우는 엔진
       └─ remove_bg.bat       (고급) 이미지를 끌어다 놓아 바로 처리

[설정 (화면 오른쪽 위 '설정' 버튼)]
  - 언어: 한국어 / English / 日本語 / 中文 (바로 적용, 다음 실행에도 유지)
  - 캐시 정리: 오류 기록·파이썬 임시 파일 삭제 (이미지는 지워지지 않음)
  - 자동 저장 경로: 확인·변경·기본값 복원·폴더 열기
  - 설정은 F:\배경투명화\settings.json 에 저장됩니다

[창 크기]
  - 창을 키우거나 줄이면 화면 전체가 비율에 맞게 커지고 작아집니다.

[결과 저장]
  기본: 원본 이미지 옆에 "transparent" 폴더가 생기고 PNG로 저장
  프로그램 안의 "저장하기 > 바꾸기" 로 원하는 폴더 지정 가능
  원본 파일은 바뀌지 않습니다.

[팁]
  - 배경이 남으면 "배경 지우기 강도"를 올리세요.
  - 그림이 깎이면 강도를 내리세요.
  - 도트 그래픽은 "경계 부드러움"을 0으로 하세요.
  - 처음 실행할 때는 준비 때문에 몇 초 걸리고, 인터넷이 필요합니다.
