============================================
  AI 게임 리소스 편집기
============================================

[실행]
  AI-Game-Resource-Editor.exe 를 더블클릭 (설치 필요 없음, 처음 실행은 몇 초 걸립니다)
  * Windows가 "PC를 보호했습니다"라고 하면  추가 정보 -> 실행  을 누르세요.
    (서명되지 않은 개인 제작 프로그램이라 나오는 안내입니다)

[사용 순서]
  1) 이미지 담기: 버튼으로 선택하거나 창에 끌어다 놓기 (폴더도 가능)
  2) 미리보기를 보며 조절 (체크무늬 = 투명)
       - 배경이 남으면 "배경 지우기 강도"를 올리세요.
       - 그림이 깎이면 강도를 내리세요.
       - 도트 그래픽은 "경계 부드러움"을 0으로 하세요.
  3) 투명화 시작!

[크기 조절 · 자르기 · 위치 (모두 선택 사항, 기본은 꺼져 있음)]
  미리보기 아래 탭에서 고릅니다. 적용 순서: 배경 지우기 -> 자르기 -> 투명 여백 자르기 -> 크기 -> 캔버스/위치
   - [크기·업스케일] 사용 안 함 / 배율로(10~400%, ×2 ×3 ×4 버튼) / 크기 지정(가로×세로 px)
        방식: 또렷하게(도트 그래픽 확대에 추천) / 부드럽게 / 선명하게
        * 배율·방식으로 화질을 "키우는" 것이지, AI로 디테일을 새로 만들어내지는 않습니다.
   - [자르기] 왼쪽(원본) 미리보기 위에 뜨는 노란 상자를 끌어서 자를 범위를 정합니다
        (스마트폰 사진 자르기처럼: 모서리 손잡이 = 크기, 상자 안쪽 = 통째로 이동)
        "전체 이미지로" 버튼으로 초기화, 투명 여백 자르기 + 남길 여백은 그 아래에서 따로 켭니다
   - [위치] "캔버스 사용"을 켜고 가로×세로를 입력하면 그 크기의 투명 캔버스 안에 그림을 배치
        9칸 격자로 정렬(왼쪽 위 ~ 오른쪽 아래) + 가로/세로 이동 + 안쪽 여백 + "크기 맞춤"
        (여러 장을 같은 크기·같은 기준 위치로 맞출 때 편해요)
  미리보기 밑에 "원본 ○○px -> 결과 ○○px" 로 최종 크기가 표시됩니다.

[결과 저장]
  기본: 원본 이미지 옆에 "transparent" 폴더가 생기고 PNG로 저장
  "저장 위치 바꾸기" 또는 설정에서 원하는 폴더 지정 가능
  원본 파일은 바뀌지 않습니다.
  "저장 이름"을 비우면 원본 파일 이름 그대로 저장됩니다.
  이름을 입력하면 그 이름으로 저장되고, 여러 장을 한꺼번에 처리할 때는
  "이름.png", "이름_2.png"처럼 자동으로 번호가 붙습니다.

[설정 (화면 오른쪽 위 '설정' 버튼)]
  - 언어: 한국어 / English / 日本語 / 中文 (바로 적용, 다음 실행에도 유지)
  - 캐시 정리: 오류 기록·임시 파일 삭제 (이미지는 지워지지 않음)
  - 자동 저장 경로: 확인·변경·기본값 복원·폴더 열기
  - 설정은 exe 옆의 settings.json 에 저장됩니다.

[창 크기]
  창을 키우거나 줄이면 화면 전체가 비율에 맞게 커지고 작아집니다.

[문제가 생기면]
  exe 옆에 error_log.txt 가 생겼다면 그 내용을 알려주세요.
